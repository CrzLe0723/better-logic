# Xnor
True when both inputs are the same
```sig
logic.xnor()
```

## Parameters
- **a**: first boolean condition
- **b**: second boolean condition

## Example

```blocks
let bool1: boolean = false
let bool2: boolean = false

if (logic.xnor(bool1, bool2)) {
  game.splash("true")
}
```
