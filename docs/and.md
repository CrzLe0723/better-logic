# And
Returns true if both conditions are true.
```sig
logic.and()
```
## Parameters
- **a**: the first boolean condition
- **b**: the second boolean condition

## Example
let num: number = 0
let num2: number = 1

```blocks
if (logic.and(num == 0, num2 == 1) {
 game.splash("true")
}
```
