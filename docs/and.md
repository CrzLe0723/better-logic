# And
Returns true if both conditions are true.
```sig
logic.and()
```
## Parameters
- **a**: the first boolean condition
- **b**: the second boolean condition

## Example


```blocks

let num = 5
let num2 = 1

if (logic.and(num == 5, num2 == 1) {
    game.splash("true")
} 
```
