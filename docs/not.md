# Not
Returns true if the input is false. Returns false if the input is true.
```sig
logic.not()
```
## Parameters
- **a**: the boolean condition

## Example


```blocks

let num = 2
let num2 = 1

if (logic.or(num == 5, num2 == 1) {
    game.splash("true")
}

```
